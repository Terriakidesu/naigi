# Naigi 0.24.0

Release date: 2026-10-01.

## Added

- Public `GET /v1/version` metadata reports the server application version and supported API version for native and desktop clients.
- Composer text selection shows an icon-only formatting toolbar for bold, italic, strikethrough, and spoiler formatting, with keyboard shortcuts.
- MIT license for Naigi's original source code, with third-party asset licenses preserved.
