# Naigi 0.23.0

Release date: 2026-09-30.

## Added

- Trusted-device history approval through private QR/link requests and matching verification codes.
- Automatic encrypted room-key backups with a separate generated recovery key, multi-device merging, and recovery-key restoration. Manual encrypted file export/import remains available.
- Account-scoped history backup/status and temporary device-transfer APIs under `/v1/crypto/history`, backed by additive migration `028_history_recovery`.
- Voice & audio preferences: page-focused push-to-talk, input/output volume, silence threshold, local microphone test, default devices, and local per-participant mute/volume.
- Automatic voice-room rejoining after reload or connection recovery, retaining tab-local mute/deafen choices until leaving, locking, or losing access.
- Permission-aware sidebar room dragging and a styled text/voice room-creation dialog with category selection.
- Grouped member actions for profiles, messaging, blocking, roles, warnings, timeouts, kicks, bans, and copying user IDs.
- Custom emoji previews and renaming without reuploading encrypted images.

## Changed

- Compact space-management views with searchable lists, list-first role management, permission- and hierarchy-restricted role ordering, and anchored member role selectors.
- Account preferences are separated into Appearance, Accessibility, Chat & media, and Notifications, retaining Save/Discard/Stay guards.
- Account and space settings omit redundant profile footers and offer subtle close buttons and Escape shortcuts. Sign out is clearly labeled under account Security; settings links use the current tab.
- Space overview fields display saved encrypted details and helpful placeholders, with unsaved-change protection.
- Sidebar room rows use tighter vertical spacing. Same-space message links render as room-icon/name → chat-icon references with in-app jumps rather than raw URLs and redundant embeds.
- Voice rooms use an audio-first participant stage with speaker activity and sidebar membership. A permanent left-footer audio strip complements in-room controls; disconnect remains separate in the connection panel.
- Date/time macros have subtle highlighting and full local-time/timezone tooltips. Reaction controls omit redundant choices, and custom emoji sections use the space name.

## Fixed

- Space settings apply saved themes, custom designs, interface scale, and cross-tab preference updates.
- Permission-restricted member actions remain visible with disabled-state explanations; role editors preserve hierarchy restrictions and unsaved-change protection.
- Compact voice device controls no longer overlap other controls or repeat their icons.
- Voice rooms verify microphone publication, report encrypted-audio subscription/playback errors, offer explicit audio unlock, and explain insecure-origin microphone limitations.
- Voice tokens support reconnects; sidebar voice presence updates and expires correctly; participant tiles no longer overlap error banners.
- Adjacent custom emoji shortcodes render correctly, including enlarged emoji-only messages.

## Security

- The server stores opaque history backup and transfer ciphertext, never readable room keys or recovery secrets. Locally remembered backup data keys are encrypted under the browser's local encryption passphrase.
- Pairing secrets stay in URL fragments and memory; requests expire after ten minutes, completed imports delete requests, and revoked participants cannot deliver queued transfers.
- Revision checks and merge-before-upload prevent silent loss of keys from concurrent backup writes. Locking/closing stops automatic updates.
- Unreadable encrypted space metadata cannot be saved as empty overview values.

Run `bun run db:migrate` before using history recovery. See [Encrypted history recovery](../history-recovery.md) for setup, limitations, and recovery instructions.
