# Naigi 0.26.0

Release date: 2026-10-02.

## Changed

- Web user assets build from the pinned `naigi-frontend` 0.2.0 submodule with Node.js/npm.
- The shared frontend gains a `mobile` build target with a phone-native interface (full-screen conversation, bottom tab bar, room drawer, and composer sheets) for the companion mobile app. Browser and desktop rendering are unchanged.
