# Naigi 0.25.0

Release date: 2026-10-01.

## Changed

- Web user assets build from the pinned Naigi frontend 0.1.2 submodule with Node.js/npm; the instance-admin console remains server-owned with an independent stylesheet.

## Fixed

- Voice rooms use one opaque participant identity per account and room, require explicit confirmation before switching devices, and reserve pending joins to prevent simultaneous duplicate connections.
- Recovery imports refresh already-open chat history without losing scroll position; startup supports automatic backup when initial network key synchronization is deferred.
- Recovery distinguishes newly added or earlier keys from duplicate imports instead of claiming history was restored when no keys improved access.
