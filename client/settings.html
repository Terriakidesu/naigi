SECURITY

Your devices

Each browser has its own encrypted key store. Revoking a device blocks future server access; it does not erase keys or messages already stored there.

PRIVACY

Your keys stay local

Your local encryption passphrase is used only to unlock this browser’s IndexedDB key store. It is never transmitted to Naigi.

Manual file backup and import

LOCAL DATA

Encrypted message cache

This browser caches encrypted message envelopes for faster history loading. The cache contains no plaintext message content and can be fetched again from the server.

Checking encrypted message cache…

Clear this browser

Removes cached encrypted envelopes, queued encrypted messages, local crypto keys, remembered unlock, device identity, and device-only preferences from this browser. It does not delete your account or server history.

Your audio, your browser

Default devices

Microphone

Processing happens locally before end-to-end encryption.

Push-to-talk shortcut

Hold the shortcut while Naigi is focused, or use the in-call hold-to-talk button. Shortcuts do not activate while typing or using form controls. Manual mute always takes priority.

In voice-activity mode, quieter input is silenced. Higher thresholds reject more background sound. Fully left disables gating. A short release delay helps preserve word endings.
